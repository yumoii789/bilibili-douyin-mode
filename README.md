# 刷B站 · B站 竖屏沉浸流（Chrome / Edge MV3 扩展）

把 B站 网页变成抖音式竖屏沉浸流；另有一个独立开关，可把**整个网页**换成 B站 Windows 桌面客户端的观感。

## 功能

- **沉浸流**：滚轮 / ↑↓ / 空格换屏与暂停；划回被回收过的屏不会黑屏；长会话下媒体与定时器都有上界
- **播放器**：全量档位菜单（未登录/无权限档位如实拒绝，**不静默降级**）、DASH 双轨音画同步与低频纠偏、宽屏 / 填充 / 16:9 / 4:3 / 21:9（**真的改变画面尺寸**）、旋转 / 镜像 / 亮度 / 对比度 / 饱和度、网页内全屏（Esc 只退全屏，不把你踢出沉浸流）、画中画、音量均衡、编码选择（avc/hevc/av1，仅 DASH 生效并如实说明）、清屏、自动连播、右键长按倍速、完整右键菜单
- **弹幕**：字号 / 速度 / 不透明度 / 显示区域 / 密度 / 类型 / 字体 / 屏蔽词；可发送（未登录与风控都有如实提示与复制出口）；发送行含「弹幕礼仪」入口与在线人数
- **互动**：点赞 / 投币 / 收藏（含收藏夹勾选）/ 三连 / 分享 / 下载 / 不感兴趣（可撤销）/ 举报反馈 / 字幕（含后台中转兜底）/ 详情页入口
- **桌面版样式**（独立开关）：整页按客户端重排 —— 侧栏导航（带图标）、**吸顶频道条**、右上搜索框、隐藏网页 footer / 顶部广告位 / 网页特有入口
- **设置页与弹窗**：全部开关与偏好；改设置**即时生效**（跨标签同步）

## 安装

1. 克隆或下载本仓库
2. `chrome://extensions`（Edge 为 `edge://extensions`）→ 打开**开发者模式** → **加载已解压的扩展程序** → 选择本目录
3. 打开 bilibili.com → 左下角出现「刷B站」（若开了桌面版样式，它在左侧栏里）

要求 **Chrome / Edge 105+**（桌面版样式用了 `:has()`，manifest 已声明 `minimum_chrome_version`）。

## 已知限制（诚实清单）

- 「不感兴趣」是否真的影响推荐、`feedback/dislike` 为何返回 -400：需要登录态真机确认
- 视频页 / 番剧播放页的观感与悬停浮层：这两类页面离线渲染不了（JS 空壳），已做 DOM 静态审计，观感待真机确认
- 抖音侧样式 1:1：抖音页面有反爬（验证码中间页 / 混淆空壳），没有可信证据源，**不硬编数值**
- 只缺「网页全屏」：固定视口下没有第二个状态，宁缺不做死按钮
